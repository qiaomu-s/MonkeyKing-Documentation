# 兼容性说明 (Compatibility)

本文说明 Monkey King 文档与运行环境的兼容范围，面向脚本使用者和集成维护者。

## 当前基线

| 项目 | 说明 |
| --- | --- |
| 产品版本 | Monkey King |
| Android | API 24 及以上 |
| JavaScript 引擎 | Rhino 2.0 语法环境 |
| 文档页面 | 122 个 canonical 页面 |
| 兼容数据 | 134 个 JSON 文件 |
| 示例 | 当前公开 API 基线中每个成员至少一个 Rhino 2.0 示例 |

`dm` 已纳入 Monkey King 的正式 API 基线，共包含 223 个公开符号（模块本身及 222 个成员）。使用前请确认运行环境提供 `dm` 全局对象及其对应的图像、字库或 OCR 资源。

## 使用建议

- 需要 Android、Java、OkHttp 或 MediaInfo 类型时，先阅读对应的权限、线程和生命周期说明。
- 需要在不同设备运行时，优先检查无障碍、Root、Shizuku、OCR、传感器和存储权限。
- 需要兼容旧脚本时，可保留文档中明确标记的历史兼容值；新脚本应优先使用当前入口和当前包名。
- 页面中的版本标签以 Monkey King 为准；旧版本行为只在影响迁移时保留说明。
