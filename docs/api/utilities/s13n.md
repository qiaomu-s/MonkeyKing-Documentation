# 标准化 (Standardization)

s13n 模块用于将多种不同类型的数据统一转换为标准类型.

例如在 Monkey King 中, 一个颜色参数通常可接受 [ [ColorHex](../types/data-types.md#colorhex) / [ColorInt](../types/data-types.md#colorint) / [ColorName](../types/data-types.md#colorname) / [Color](../types/color.md) / [ThemeColor](../types/data-types.md#themecolor) ] 等多种类型:

```js
console.setBackgroundColor('orange');
console.setBackgroundColor('#663399');
console.setBackgroundColor(monkeyking.themeColor);
console.setBackgroundColor(Color('blue').setAlpha(0.75));
```

上述这些颜色设置方式均有效.<br>
但安卓 API 中涉及颜色的参数往往只接受 `ColorInt` 类型:

```js
activity.window.setStatusBarColor('orange'); /* 抛出异常. */
activity.window.setStatusBarColor(Color('orange')); /* 抛出异常. */
activity.window.setStatusBarColor(Color('orange').toInt()); /* 正常. */
activity.window.setStatusBarColor(colors.toInt('orange')); /* 效果同上. */
```

上述示例的颜色参数只能使用 `ColorInt`, 对应 JavaScript 的 `number` 类型.

s13n 模块对颜色参数统一转换为 `ColorInt`:

```js
s13n.color('red'); /* 相当于 colors.toInt('red') . */
```

因此对于上述设置通知栏颜色的示例, 使用 s13n 模块即可不必关心参数原本的类型:

```js
activity.window.setStatusBarColor(s13n.color('orange')); /* 正常. */
activity.window.setStatusBarColor(s13n.color(Color('orange'))); /* 正常. */
activity.window.setStatusBarColor(s13n.color(Color('orange').toInt())); /* 正常. */
activity.window.setStatusBarColor(s13n.color(Color('orange').toHex())); /* 正常. */
```

不过对于 Monkey King 内置模块 (colors, device, images 等), 传参时无需使用 s13n 进行标准化.<br>
因为在模块内部的实现代码中, 已经借助 s13n 进行了标准化操作.<br>
例如以下代码片段是 `console.setBackgroundColor` 的内部实现代码:

```js
function setBackgroundColor(c) {
    return runtime.console.setBackgroundColor(s13n.color(c));
}
```

上述示例可以看出, s13n 模块对参数 `c` 进行了颜色标准化操作.

|-------------------|----|----------------------------------|--------------------------------|
| [color](#m-color) | 颜色 | [OmniColor](../types/omni-types.md#omnicolor) | [ColorInt](../types/data-types.md#colorint) |

## [m] color

### color(o)

- **o** { [OmniColor](../types/omni-types.md#omnicolor) }
- <ins>**returns**</ins> { [ColorInt](../types/data-types.md#colorint) }

将颜色参数 `o` 标准化为 [ColorInt](../types/data-types.md#colorint).

```js
s13n.color('red') === s13n.color('#F00'); // true
s13n.color('#FB663399') === s13n.color(0xFB663399); // true
```

## [m] throwable

### throwable(o)

- **o** { [OmniThrowable](../types/omni-types.md#omnithrowable) }
- <ins>**returns**</ins> { [java.lang.Throwable](../../reference/runtime/exceptions.md#java) }

将可抛异常参数 `o` 标准化为 [java.lang.Throwable](../../reference/runtime/exceptions.md#java) 类型.

```js
let a = s13n.throwable('error message');
let b = s13n.throwable(Error('error message'));
let c = (/* @IIFE */ () => {
    try {
        nothing++;
    } catch (e) {
        return s13n.throwable(e.rhinoException);
    }
})();

[ a, b, c ].every(o => o instanceof java.lang.Throwable); // true
```

## 实现合同补充方法

以下方法与 `color`、`throwable` 一样同步执行，不持有外部资源，版本记作 **≤ v6.6.4（旧文档未记录精确版本）**。

### s13n.point(value, y?)

接受 1 至 2 个参数并返回 `android.graphics.Point`：

- Android `Point`：原样返回。
- OpenCV `Point`：将 `x`、`y` 截断为整数。
- 数组：读取前两个元素并转换为整数。
- 对象：读取 `x`、`y` 属性并转换为整数。
- 数字：作为 `x`；第二个参数缺省或转为 `NaN` 时令 `y = x`，否则将第二个参数四舍五入为整数。

未知类型、缺少坐标或数值转换失败会抛出参数异常。

```js
console.log(s13n.point([10, 20]));     // Point(10, 20)
console.log(s13n.point({ x: 3, y: 4 }));
console.log(s13n.point(8));            // Point(8, 8)
```

### s13n.time(source, fromUnit?, toUnit?)

接受 1 至 3 个参数，返回转换后的 `number`。数字默认按毫秒解释，目标单位也默认毫秒；单位可使用 `java.util.concurrent.TimeUnit`，或不区分大小写的纳秒、微秒、毫秒、秒、分钟、小时、天的常见英文缩写。第二个参数也可写成 `{ fromUnit, toUnit }`。

`Date` 会先转换为时间戳；包含完整“年、月、日、时、分、秒”六段的字符串先按日期解析。非法数字、未知单位或找不到转换函数时抛出异常。

```js
console.log(s13n.time(2, 'seconds', 'milliseconds')); // 2000
console.log(s13n.time(3, { fromUnit: 'minutes', toUnit: 'seconds' })); // 180
```

### s13n.bytes(source, fromUnit?)

接受 1 至 2 个参数，把数值字节单位统一为整数 byte。省略 `fromUnit` 时按 byte 解释；提供第二个参数时必须是字符串单位，支持值以 [cvt.bytes](converter.md) 的字节单位解析规则为准。非法参数数量、非字符串单位或不可转换数值会抛出异常。

```js
console.log(s13n.bytes(2, 'KB'));  // 2048
console.log(s13n.bytes(1.5, 'MB'));
```

这些转换本身无需 Android 权限且没有持久副作用；若外部输入值来自文件、网络或硬件，资源生命周期仍由相关 API 管理。
