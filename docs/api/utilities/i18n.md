# 国际化 (Internationalization)

**自 v6.2.0 起提供。**

本文于 2026-09-10 按 Monkey King 当前产品行为核对。

全局属性 `i18n` 在首次访问时延迟加载应用内置 `i18n.js`。实现基于固定打包的 `banana-i18n.js`，并增加本地 JSON 目录、自动加载和默认语言约定。

每个脚本运行时持有自己的 i18n 实例。默认目录是当前脚本工作目录下的 `i18n/`；初始化时同步加载其中全部 `.json` 文件，并把 locale 设为 `default`。目录不可用时会尝试应用 assets 下的同名目录。

## [@] i18n

### i18n(messageKey, ...params)

**`6.2.0`** **`Global`**

- **messageKey** { [string](../types/data-types.md#string) }
- **params** { [...any[]](../types/data-types.md#any) } - 消息占位参数
- <ins>**returns**</ins> { [string](../types/data-types.md#string) }
- **异常**：消息解析器遇到非法语法时抛出异常
- **副作用 / 生命周期**：读取当前实例已加载的消息与 locale，不执行文件 I/O

找不到消息时，Banana-i18n 最终返回 messageKey 本身。

```js
// i18n/default.json: { "hello": "你好，$1" }
i18n.setLocale('default');
console.log(i18n('hello', 'Monkey King')); // 你好，Monkey King
```

## [p] banana

### i18n.banana

**`6.2.0`** **`Writable`** **`Implementation object`**

- { [Object](../types/data-types.md#object) } - 内置 Banana-i18n 实例
- **异常**：无
- **副作用**：直接调用其方法会绕过 Monkey King 的路径包装

```js
console.log(i18n.banana.getMessage('hello'));
```

`banana` 是普通可写属性，但给 `i18n.banana` 重新赋值不会替换闭包捕获的原始 Banana-i18n 实例。可调用的 i18n 函数和包装方法仍使用原始实例；赋值只改变公开属性随后读到的对象。若直接修改原始 `i18n.banana` 实例本身，其状态仍会影响解析。`i18n.constructor` 也会暴露包装构造函数，但属于实现细节；业务代码不应自行实例化该构造函数。

```js
const original = i18n.banana;
i18n.banana = { getMessage: () => 'replacement only' };

console.log(i18n.banana.getMessage('hello')); // replacement only
console.log(i18n('hello')); // 仍由 original 解析，而不是 replacement only

i18n.banana = original;
```

## [m] setPath

### i18n.setPath(relativePath)

**`6.2.0`**

- **relativePath** { [string](../types/data-types.md#string) } - 已存在的目录
- <ins>**returns**</ins> { [void](../types/data-types.md#void) }
- **异常**：目标不是目录时抛出 `Error`
- **副作用 / 生命周期**：修改当前运行时后续加载消息所用目录；不会卸载已加载消息

```js
i18n.setPath(files.join(files.cwd(), 'messages'));
```

## [m] getPath

### i18n.getPath()

**`6.2.0`**

- <ins>**returns**</ins> { [string](../types/data-types.md#string) }
- **异常**：文件系统查询失败时可能抛出异常
- **副作用**：当前目录无效但 assets 下存在回退目录时，会把路径更新为该回退目录

```js
console.log(i18n.getPath());
```

## [m] setLocale

### i18n.setLocale(locale)

**`6.2.0`**

- **locale** { [string](../types/data-types.md#string) }
- <ins>**returns**</ins> { [void](../types/data-types.md#void) }
- **异常**：底层 parser 无法接受 locale 时抛出异常
- **副作用 / 生命周期**：替换当前实例的 parser，并影响后续消息查找

```js
i18n.setLocale('zh-CN');
```

### i18n.getFallbackLocales()

**`6.2.0`**

- <ins>**returns**</ins> { [string](../types/data-types.md#string)[] }
- **异常**：无
- **副作用**：无


## [m] load

### i18n.load(messageSource, locale?)

**`6.2.0`**

- **messageSource** { [Object](../types/data-types.md#object) | [string](../types/data-types.md#string) } - 消息对象、JSON 路径或 locale 名称
- **[ locale ]** { [string](../types/data-types.md#string) }
- <ins>**returns**</ins> { [void](../types/data-types.md#void) }
- **异常**：文件不存在、JSON 解析失败、消息格式非法或输入类型不支持时抛出异常；JSON 错误同时写入警告日志
- **线程 / 副作用**：字符串来源会同步读取文件，并把消息合并到当前实例

对象输入直接交给 Banana-i18n。字符串只有一个参数时同时作为文件名与 locale；不含系统路径分隔符时从当前目录加载 `<name>.json`。

```js
i18n.setPath(files.join(files.cwd(), 'messages'));
i18n.load('zh-CN');
i18n.setLocale('zh-CN');
console.log(i18n('app-title'));
```

```js
i18n.load({
    default: { greeting: 'Hello' },
    'zh-CN': { greeting: '你好' },
});
```

## [m] loadAll

### i18n.loadAll()

**`6.2.0`**

- <ins>**returns**</ins> { [void](../types/data-types.md#void) }
- **异常**：目录读取、单个文件读取或 JSON 解析失败时抛出异常
- **线程 / 副作用**：同步读取当前目录中全部 `.json` 文件，并合并到当前实例

文件名去掉扩展名后作为 locale。文件较多时不要在 UI 线程调用。

```js
i18n.setPath(files.join(files.cwd(), 'messages'));
i18n.loadAll();
```

完整消息语法参阅 [Banana-i18n 官方参考资料](https://github.com/wikimedia/banana-i18n)。
